Built like a chess tool, not a dashboard

Stockfish decides

Every evaluation, best move and principal variation comes from a real UCI engine at a depth you choose. A deeper second pass runs on critical positions.

Nine classifications

Brilliant, Great, Best, Excellent, Good, Book, Inaccuracy, Mistake, Blunder — derived from win-probability loss, not raw centipawns.

Accuracy that is explained

A documented formula, per phase, with the limitations written down. No claim to reproduce anyone's proprietary numbers.

Zero JavaScript

HTML and CSS only. A C++ backend serves the pages over loopback and the WebView runs with scripting disabled.

Real opening book

Book moves come from the CC0 Lichess opening data, never from a language model, and a book label can never hide a blunder.

Explanations, grounded

Gemini receives the engine's findings through a proxy you host and is told to use nothing else. No key ever ships inside the app.

From PGN to review in three steps

  1. Import. Pick a .pgn file or paste the notation.
  2. Analyse. Stockfish scores every position, with progress you can watch and cancel.
  3. Review. Walk the board, read each classification and the per-move panel, then ask for an explanation.

Why this page is not the app

WeChess's logic is a native C++ server, so it runs on Android, not in a serverless host. This site is the download and documentation page; the APK is built by GitHub Actions from the same repository.
